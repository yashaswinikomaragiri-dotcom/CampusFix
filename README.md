# CampusFix – Campus Maintenance Complaint & Tracking System

CampusFix is a web-based system for registering and tracking campus maintenance complaints.

## Features
- Register maintenance complaints
- View and search complaints
- Update complaint status
- Add maintenance details
- View complaint reports and analysis
- Track Pending, In Progress and Resolved complaints

## Complaint Categories
- Electrical
- Furniture
- Plumbing
- IT
- Internet
- Cleaning
- AC/Cooling
- Other

## Technology Used
- HTML
- CSS
- JavaScript
- Local Storage

## Project Workflow
Register Complaint → Save Complaint → View/Search → Update Status → Add Maintenance → Reports & Analysis

## Project Purpose
The system helps students and campus staff manage maintenance complaints in an organized way and track their resolution status.
